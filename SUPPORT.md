# Getting help

For the coffee journal, start with the
[documentation](https://github.com/michidk/roastbook#-documentation), including
configuration, deployment, and upgrade instructions.

Search issues in the relevant repository before opening a new question or bug
report. Include your version, deployment method, steps to reproduce, and
relevant redacted logs. Never include API keys, passwords, session tokens, or
private journal data.

For coffee datasets, schemas, and tooling, use the issue tracker in the
repository that owns the affected data or behavior.

Roastbook is maintained as an open-source project. Responses depend on
maintainer availability; there is no guaranteed response time.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
