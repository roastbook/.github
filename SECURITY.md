# Reporting a security vulnerability

Do not disclose vulnerabilities, exploit details, credentials, or private user
data in public issues or pull requests.

In the affected repository, open **Security → Advisories → Report a
vulnerability** to send a private report to its maintainers.

If that option is unavailable, email [hello@roastbook.coffee](mailto:hello@roastbook.coffee)
with a brief description and ask for a private channel before sending sensitive
attachments.

A useful private report includes the affected repository and version, the
impact, reproduction steps, and a minimal proof of concept using synthetic
data. Do not access other people's data or test systems without permission.

Repository-specific security policies take precedence over this default.
Unless a repository documents a support policy, do not assume older releases
receive security fixes; use the latest stable release where possible.

Please coordinate public disclosure with the maintainers so they can
investigate and prepare a fix. Response times depend on maintainer availability.
